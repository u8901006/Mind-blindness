Aphantasia & Mind Blindness Daily Research Briefing

今日研究概覽

今日的文獻收錄了近期《Neuropsychologia》與《Consciousness and Cognition》關於 aphantasia 的重要專輯，顯示該領域正從單純的現象描述邁向嚴謹的認知神經機制解構。最核心的突破來自對 55 名皮質盲 患者的系統性回顧，該研究強力挑戰了初級視覺皮層 ( V1 ) 是視覺心像 必要條件的傳統假設，將神經學焦點轉向左側顳葉網絡。同時，多項研究證實了視覺意象與視覺工作記憶、語言理解中的心理模擬是可分離的認知機制。在方法學上，單一題項的 VVIQ 篩檢工具問世，大幅提升了大規模流行病學研究的可行性；而跨世代的分佈調查則進一步穩固了心盲症與超級想像力 作為連續光譜兩端的發展心理學觀點。此外，現象學與哲學意識的介入，為理解無意象狀態下的抽象思維與主觀體驗提供了更深層的理論框架。

  • 亮點1：55 例皮質盲回顧研究推翻 V1 必要性假說，證實左側顳葉的 fusiform imagery node ( FIN ) 才是視覺心像的關鍵神經中樞。
  • 亮點2：透過多變素模式分析 ( MVPA ) 神經影像技術，首次在行為與神經編碼層面雙重證實心盲症者的視覺工作記憶並未受損。
  • 亮點3：成功將傳統 16 題的視覺意象鮮明度問卷 ( VVIQ ) 精簡為具備高靈敏度的單一題項篩檢工具。
趨勢觀察：Aphantasia 研究正經歷顯著的「解耦趨勢」：學界不再將其視為一種單一的全面性缺陷，而是致力於將「視覺意象」與其他視覺認知功能（如工作記憶、語意理解、抽象推理）精確解耦。同時，跨學科整合（神經心理學、現象學、哲學）正在推動建立更精確的操作型定義，以應對該群體內部的顯著異質性。
