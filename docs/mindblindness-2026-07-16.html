今日研究概覽

今日的 aphantasia （心盲症）研究文獻呈現高度多元化的發展，顯示該領域已從單純的「視覺意象缺失」探討，邁向更深層的認知機制解碼與現象學考察。在神經機制方面，最重大的突破是透過 55 個案例回顧，正式確立了 cortical blindness （皮質盲）與 aphantasia 之間的雙重解離，這為證明兩者獨立運作提供了決定性證據。在認知功能上，研究發現 aphantasia 個案在 face perception （臉孔知覺）與 face memory （臉孔記憶）上存在獨立受損，且在複雜虛擬環境中呈現空間記憶與導航困難；然而，他們在缺乏視覺意象的情況下，仍能透過非視覺策略完美執行 associative memory （關聯性記憶）任務，顯示大腦具有強大的認知補償機制。此外，透過 eye-tracking （眼動追蹤）技術發現心盲症者在心理地圖探索時的眼動模式與視覺化者相似，挑戰了「視覺意象必然伴隨空間眼動」的傳統假設。最後，關於自閉症共病率、多模態意象特徵以及生活經驗的質性研究，進一步豐富了 aphantasia 在發展心理學與現象學層面的輪廓。

  • 亮點1：透過 55 個案例系統性回顧，正式確立 cortical blindness 與 aphantasia 的 double dissociation （雙重解離），釐清兩者在本質上的差異。
  • 亮點2：Aphantasia 個案在 face perception 與 face memory 表現出獨立受損，但在 face matching （臉孔比對）任務上表現正常，顯示其臉孔處理缺陷具有特定認知階段的選擇性。
  • 亮點3：在 associative memory 任務中，心盲症者表現與對照組相當甚至更優，證實其自傳式記憶的細節缺失並非源於基礎關聯記憶缺陷，而是策略差異。
趨勢觀察：研究趨勢觀察：近期的 aphantasia 研究正經歷從「特徵描述」向「機制解碼」的範式轉移。學界不再滿足於確認受試者「看不到」，而是精細拆解其在空間導航、臉孔辨識、動作意象等特定認知模組的表現差異，並探討其背後的非視覺補償策略。同時，跨領域整合趨勢明顯，結合認知神經科學、發展心理學（如自閉症光譜的交集）與現象學，試圖建構更完整的 aphantasia 生態效度圖像。
