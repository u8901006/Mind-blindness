今日研究概覽

今日的文獻顯示出對 aphantasia（心盲症）進行多面向探討的顯著趨勢，這以 2026 年 Neuropsychologia 期刊的專刊為核心。研究跨越了從基礎認知機制（如空間記憶、語句理解時的 mental simulation、visual working memory）到現象學與哲學意識基礎（如「暗幕」後的生活體驗、對 Humean abstraction 理論的挑戰）的廣泛領域。值得注意的是，一篇研究證實了 aphantasia 與複雜虛擬環境中空間導航困難之間的具體關聯，而另一篇研究則透過 multivoxel pattern analysis (MVPA) 發現，儘管缺乏視覺意象，視覺工作記憶仍完好無損。此外，大規模的盛行率研究強調了向 multimodal mental imagery（多模態心理意象）輪廓評估轉變的趨勢，超越了單純的視覺生動度測量。這些發現共同推動了該領域從單純的特徵描述，轉向機制性解離與概念性的嚴謹驗證。

  • 亮點1：心盲症患者在複雜虛擬環境中展現出顯著的空間記憶與導航障礙，直接證實 visual imagery 對空間認知的核心貢獻。
  • 亮點2：神經影像與行為數據雙重確認，aphantasia 患者的 visual working memory 功能完整，挑戰了「缺乏意象必損害短期視覺保留」的傳統假設。
  • 亮點3：透過現象學與哲學視角重新定義心盲症，指出其不僅是感知缺陷，更作為反例對經驗主義的抽象概念理論構成根本性挑戰。
趨勢觀察：研究正從單純的「視覺生動度」測量，轉向「多模態心理意象」的輪廓分析；同時，方法學上逐漸拋棄冗長問卷，發展單一題目篩檢工具，並結合 virtual reality (VR) 與神經影像學技術，精確解離出意象在認知功能（如記憶、語言理解）中的獨立角色。
