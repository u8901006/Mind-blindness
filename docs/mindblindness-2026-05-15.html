今日研究概覽

今日共篩選出 8 篇與 aphantasia 高度相關的核心文獻，其中多數發表於《Neuropsychologia》2026 年 6 至 7 月的專刊中。這批研究標誌著心盲症領域正從單純的現象描述，邁向概念嚴謹化、認知機制驗證與測量工具優化的新階段。研究涵蓋了現象學的生活經驗探究、語句理解中的心理模擬、對休謨抽象哲學理論的挑戰，以及透過 multivoxel pattern analysis (MVPA) 對 visual working memory 的神經影像學驗證。此外，針對不同年齡層的意象分佈調查與單一題項篩檢工具的開發，為未來的大規模流行病學研究與臨床篩檢奠定了重要基礎。

  • 透過 fMRI 與 MVPA 技術證實 aphantasia 個體的 visual working memory 在行為與神經層面皆未受損，挑戰了過去認為視覺意象缺失會導致工作記憶缺陷的假設。
  • 從哲學意識角度出發，以 aphantasia 作為關鍵反例，直接挑戰了休謨基於心理意象的抽象理論，拓寬了認知科學與哲學的對話邊界。
  • 提出將 VVIQ 簡化為單一題項作為 aphantasia 的篩檢工具，大幅降低了未來跨領域研究的參與門檻與測量負擔。
趨勢觀察：近期 aphantasia 研究呈現「機制解構與概念辯證並重」的趨勢。學界不再滿足於確認「看不到」，而是深入探討「看不到時大腦如何替代運作」（如語意處理、空間導航的替代策略）。同時，哲學視角的引入顯示該領域正試圖解決意識本質的硬問題。
