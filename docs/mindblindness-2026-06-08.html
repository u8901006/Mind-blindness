今日研究概覽

今日的 aphantasia （心盲症）研究文獻迎來大爆發，主要以 Neuropsychologia 期刊的專題為核心，共計 9 篇高質量文獻。這批研究標誌著該領域從「現象描述」邁向「機制解析」與「概念精煉」的關鍵轉折。過去研究多聚焦於視覺意象生動度的主觀評估，但今日文獻顯示，學界開始深入探討心盲症在空間導航、語句理解等高階認知功能的具體影響。特別值得注意的是，透過 multivoxel pattern analysis (MVPA) 等神經影像技術，研究者在視覺工作記憶任務中未發現受損證據，這為區分「意象生成」與「短期視覺儲存」提供了關鍵的神經科學依據。此外，跨年齡層的盛行率調查與單一題目篩檢工具的開發，顯示該領域正積極建立更完善的測量基礎設施，以利未來大規模的跨領域應用。

  • 亮點1：首次在複雜虛擬環境中實證 aphantasia 患者的空間記憶與導航能力確實受損，擴展了心盲症的認知影響範圍。
  • 亮點2：運用神經影像 MVPA 技術證實心盲症患者的 visual working memory 未受損，支持其缺陷僅在於「意象提取」而非「視覺儲存」。
  • 亮點3：將冗長的 VVIQ 問卷簡化為單一題目篩檢工具，大幅提升大規模流行病學研究的可行性。
